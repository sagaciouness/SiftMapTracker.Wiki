# 导航总览

导航总览是独立地图窗口，用于查看完整路线、当前位置、当前目标和进度。

## 打开方式

- 在“追踪总览”的“当前路线”卡片点击“导航总览”；
- 使用默认快捷键 `Alt + F8`；
- 再次触发会激活已有窗口，不会重复创建多个窗口。

## 地图操作

- 鼠标滚轮：以指针位置为中心缩放；
- 左键或中键拖动：平移；
- “居中到玩家”：快速回到当前位置；
- “适应路线”：缩放到完整路线范围。

看不到当前位置时，先查看窗口上方的“定位”，再到[追踪总览](/tracking/)确认是否已取得位置。看不到目标节点时，到[开始导航](/navigation/)确认已选择路线并开始导航。需要移动或增删节点时，打开[路线编辑](/editors/routes)。

侧栏“开始导航”页也提供可缩放的只读地图，并且同时承担路线导航/自由探索的配置与开始、停止操作；“导航总览”仍适合单独开窗长期观察。
