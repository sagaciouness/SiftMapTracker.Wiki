# 路线导航

## 单路线模式

单路线模式只使用当前路线文件。选择路线后启动导航，服务按路线节点和连线计算进度、下一节点和距离。

## 多路线模式

多路线模式可加载多个候选路线。软件发现更适合的路线时给出切换建议，默认不会在需要确认的场景中静默替换路线。

- `Ctrl + Shift + F8`：确认当前路线切换建议。
- `Ctrl + Shift + F9`：忽略当前建议，五分钟内不再提醒。
- `Ctrl + Shift + F10`：在当前位置重新开始导航。

## 路段接续提示

定位连续五帧落在当前目标以外的同一路线路段时，灵动岛会给出接续建议，软件不会在玩家确认前自动修改进度。

- 落在之前走过的路段：按 `Ctrl + Shift + F8` 后回退到该处，该点之后的完成状态需要重新记录。
- 落在更靠后的未完成路段：确认后从该处继续，中间没有命中的点保持灰色，后续实际命中的点仍可正常完成。
- 按 `Ctrl + Shift + F9` 只忽略当前具体路段，五分钟内不会重复提示。
- 传送段和无法可靠区分的路线交叉点不会触发接续建议。

到达终点后导航正常结束。若中途存在漏点，灵动岛会显示“路线已完成 · 漏记 N 点”，不会强制玩家返回补漏。

## 常用流程

1. 在路线配置区选择导航模式和路线文件。
2. 启动追踪并等待定位成功。
3. 点击“路线导航开始”。
4. 使用 HUD 或导航总览观察下一节点和路线进度。
5. 发现路段接续提示时可确认继续；只有定位或进度完全异常时才使用“在此位置重新导航”。

停止追踪服务时，导航开关和 HUD 状态也应恢复为停止，避免客户端与服务状态不一致。
