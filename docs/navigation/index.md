# 地图追踪：路线导航与自由探索

地图追踪工作台按职责分为四个入口：

- **追踪总览**：配置截图区域、启动或停止地图定位服务，并查看实时定位状态。
- **开始导航**：选择路线导航或自由探索，浏览路线、资源点和实时玩家位置，并开始或停止一次导航/探索会话。
- **路线编辑**：新建、绘制、重命名和导出路线，不负责启动导航。
- **导航记录**：查看已经保存的路线导航与自由探索轨迹。

旧版本升级用户启动软件后仍默认进入“追踪总览”，用途仍默认使用“路线导航”；切换用途不会清除或改写已经保存的路线进度。

## 用途切换

- **路线导航**：使用单路线、多路线、路段接续和现有路线进度。
- **自由探索**：只使用定位服务输出的未吸附真实坐标，不推进路线节点；灵动岛地图框仍显示玩家位置和当前资源文件中的资源点。

追踪活动期间会锁定用途和记录选项。需要切换时，先停止当前路线导航或自由探索记录。

用途、路线和记录选项统一放在侧栏的“开始导航”页面。页面左侧地图会显示当前资源点、路线和玩家位置；右侧用于选择模式并开始或停止会话。启动后页面不会自动跳转，仍可缩放和平移地图。

右栏下方的“灵动岛显示”卡可快捷调整整体缩放、地图缩放和边缘黑框透明度，也可重置灵动岛位置。这些选项只改变悬浮显示，不影响左侧路线地图、定位、路线进度或导航记录；导航已经开始后仍可调整。

地图支持以鼠标位置为中心滚轮缩放，按住左键或中键拖动平移，并提供“适应路线”“适应全图”“100%”和“居中玩家”。实时定位只更新玩家、节点状态和实际轨迹，不会打断玩家当前视口。多路径模式下，“适应路线”会包含所有正在预览的候选路线。

在“开始导航”页显式选择路线后，地图会切换到 `100%` 并以该路线第一个节点为中心；起点使用绿色“起”标记与普通节点区分。之后玩家手动缩放或平移时，实时定位不会擅自重置视口。

## 自由探索

自由探索包含两个可以同时开启的记录器，至少需要开启一项才能开始。首次使用默认只开启“轨迹记录”。

### 区域涂抹

区域涂抹表示玩家曾进入该范围，不代表范围内每个资源或炫彩都已逐一检查。路线导航和自由探索共用当前地图的一张累计涂抹图，半径可在 `25–200 米` 之间调整，默认 `100 米`；按完整地图 `4080 米 / 8192px` 换算，100 米约为 201 个地图像素。涂抹使用未吸附的真实坐标和轨迹同款防抖规则，连续移动之间使用圆角连接，传送或重新定位后只在新位置落圆，不会涂过中间区域。

### 色弱友好调色盘



每次点击“自由探索开始”都会建立一个独立行程会话。默认只显示本次轨迹；开启“显示历史轨迹”后，旧版轨迹会以较低透明度叠加。停止、异常退出或关闭客户端时都会保存当前记录。开启区域涂抹时，该行程还会保存结束时的完整累计涂抹快照，方便日后回看当时已经覆盖的范围。

轨迹使用五帧滚动中值抑制定位抖动：首次定位和恢复需要三帧稳定结果，3px 内移动被视为抖动，累计移动达到 5px 才写入。单次跳变超过 80px、定位丢失超过 2 秒或发生传送时会结束当前线段，新位置稳定后另起一段，避免把两个区域错误连线。

### 显示与数据

自由探索时，灵动岛和导航总览按以下顺序显示：底图、区域涂抹或历史轨迹、当前轨迹、资源点、玩家光标。路线节点、路线警告和路段接续提示会隐藏。

记录按当前地图文件的 SHA-256 隔离，保存在：

```text
%LOCALAPPDATA%\SiftMapTracker\exploration\v1\<地图 SHA-256>\
```

地图更新后会自动进入新的目录。损坏或地图信息不匹配的文件会先备份再忽略，不会阻止定位。界面提供“清空累计涂抹”和“清空轨迹历史”，操作前均会二次确认。清空累计涂抹会同时影响路线导航与自由探索的共享遮罩，但不会删除已经保存到导航记录中的历史快照。

## 路线导航

路线导航设置中可以分别开启“记录导航轨迹，同时开启导航记录”和“区域涂抹，同时开启导航记录”，两个选项默认关闭，单路线和多路线共用。轨迹或涂抹任一开启时，从点击“路线导航开始”起建立一条导航记录；两者都关闭时保持原有路线导航行为，不创建记录。仅开启涂抹时也会保存一条没有实际轨迹、但包含结束时累计涂抹快照的导航记录。

实际轨迹和累计涂抹会实时叠加在灵动岛地图框、开始导航地图和导航总览中，但不会隐藏路线、路线节点、资源点或接续提示，也不会改变导航进度。显示顺序为底图、累计涂抹、路线或候选路线、实际轨迹、节点与资源、玩家位置。多路线自动或手动切换不会拆分记录；停止、完成、服务退出会结束本次记录，`Ctrl + Shift + F10` 重新导航会先保存旧记录再创建新记录。
## 单路线模式

单路线模式只使用当前路线文件。选择路线后启动导航，服务按路线节点和连线计算进度、下一节点和距离。

## 多路线模式

多路线模式可加载多个候选路线。软件发现更适合的路线时给出切换建议，默认不会在需要确认的场景中静默替换路线。

- `Ctrl + Shift + F8`：确认当前路线切换建议。
- `Ctrl + Shift + F9`：忽略当前建议，五分钟内不再提醒。
- `Ctrl + Shift + F10`：在当前位置重新开始导航。

## 路段接续提示

定位落在与当前目标至少相隔 4 个节点的同一路线路段，并连续五帧保持稳定时，灵动岛才会给出接续建议。刚踩过节点后仍停留在原地、或只偏离相邻几个节点时不会提示；软件也不会在玩家确认前自动修改进度。

- 落在之前走过的路段：按 `Ctrl + Shift + F8` 后回退到该处，该点之后的完成状态需要重新记录。
- 落在更靠后的未完成路段：确认后从该处继续，中间没有命中的点保持灰色，后续实际命中的点仍可正常完成。
- 按 `Ctrl + Shift + F9` 只忽略当前具体路段，五分钟内不会重复提示。
- 传送段和无法可靠区分的路线交叉点不会触发接续建议。

到达终点后导航正常结束。若中途存在漏点，灵动岛会显示“路线已完成 · 漏记 N 点”，不会强制玩家返回补漏。

## 常用流程

1. 在“追踪总览”启动追踪；定位服务可以先运行，启动导航不会替代这一步。
2. 打开侧栏“开始导航”，选择用途、导航模式和路线文件。
3. 点击“路线导航开始”或“自由探索开始”。
4. 在本页地图、HUD 或导航总览观察玩家位置、下一节点和路线进度。
5. 发现路段接续提示时可确认继续；只有定位或进度完全异常时才使用“在此位置重新导航”。

停止追踪服务时，导航开关和 HUD 状态也应恢复为停止，避免客户端与服务状态不一致。
## 导航记录

地图工作台侧栏“追踪总览”下方提供“导航记录”。页面采用工作台布局：顶部工具卡集中显示记录数量、磁盘占用、筛选和管理操作；左侧为大地图；右侧依次提供记录列表、详细信息和预览控制。每一项代表一次开始到停止、完成或中断的周期，包含模式、路线名称、开始和结束时间、持续时间、实际里程以及分段轨迹。自由探索或路线导航启用涂抹时，还可预览该次结束时的累计涂抹图，并使用当前全局涂抹颜色显示。底图已经加载但尚未选择记录时，页面会提示从右侧选择记录，不会误报底图缺失。

- 可按“全部记录 / 路线导航 / 自由探索”筛选，记录按开始时间倒序排列。
- 地图预览只在选中记录后后台加载；大量历史不会在进入页面时一次性解码全部 PNG。
- 支持重命名、删除单条和清空当前地图记录。删除历史不会清除当前累计涂抹。
- 活动行程保存完成前不能重命名、删除或清空，防止较早的自动保存覆盖玩家刚做的管理操作。
- 异常退出留下的自动保存会显示为“中断保存”，仍然可以预览。
- 旧版自由探索轨迹会以只读记录显示；旧累计涂抹无法可靠归属到某次会话，因此不会猜测关联。

地图预览支持以鼠标所在位置为中心滚轮缩放（约 5%–400%），按住左键或中键拖动可以平移；右侧“预览”卡可一键“适应全图”或恢复到“100%”，并显示当前缩放比例与鼠标地图坐标。首次进入页面会自动适应全图；选择一条含轨迹的记录后，地图会切换到 100%、居中首个有效轨迹点，并使用绿色“起”标记起点。刷新同一条记录不会覆盖玩家之后的手动缩放和平移；仅含涂抹或没有有效轨迹点的记录保持适应全图。

导航记录永久保留，由玩家手动管理，保存在当前地图目录的 records 子目录：

```text
%LOCALAPPDATA%\SiftMapTracker\exploration\v1\<地图 SHA-256>\records\
```

程序每五秒原子更新当前活动记录，不会产生多个历史版本；停止或完成后的最终快照保存结束前，记录管理按钮会保持锁定。若最终保存失败，客户端会明确提示并保留最后快照供立即重试，不会把失败误报为成功，也不会关闭客户端或中断定位。长轨迹预览会在不修改原始记录的前提下限制单段绘制点数，避免数小时记录拖慢页面。
