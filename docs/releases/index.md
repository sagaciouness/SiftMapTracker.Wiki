# 版本记录

正文只描述最新稳定版。本页保留各版本的主要变化，便于升级和排查版本差异。

::: info 当前算法
当前版本只提供 SIFT 与模板匹配（TM）。ORB 仅在部分历史版本中出现，现已移除。
:::

## Windows v0.9.7

- 童话血脉识别增加橙色高亮词快路径，自动在玩家粗框的横幅附近寻找“奇异、污染、混乱、异色”，减少偏框和不同比例画面带来的漏识别。
- 快路径采用连续一致结果确认；无法得到唯一可靠结果时再识别完整横幅句子，避免单帧噪声造成误判。
- 血脉仍采用保守记录策略：缺失、低置信度或冲突时记为“未识别”，事件照常累计并继续监测，不产生人工确认阻塞。

## Windows v0.9.6

- 路线导航可在连续五帧稳定落到非当前路段时通过灵动岛建议接续，确认前不会自动修改进度。
- 回到旧路径时支持严格回退；向前接续时保留漏点为灰色，后续点位改为独立完成，不再被中间漏点卡住。
- 到达终点后即使存在漏点也会正常结束，并明确显示漏记数量。
- 童话事件取消人工复核阻塞，结果字段不完整或冲突时仍会自动记录并继续监测。
- 启动时优先使用当前玩家包内的地图服务与资源，避免少部分旧版本配置把新客户端路由到历史资源目录。

## Windows v0.9.5

- 小于 `164px` 的 SIFT 选区改为在框选确认后按短边准备动态 160 缓存，不再等待运行中的圆检测。
- 动态缓存使用顺序重叠分块生成，将最低可用内存要求降至 4 GB，并增加真实百分比、分块数量和平滑进度条。
- 地图与屏幕识别框选器升级为高对比聚光界面；截图前自动隐藏全部客户端窗口，结束后精确恢复。
- 血脉达到可靠门槛后立即更新童话页面并弹出灵动岛提示；童话事件经双帧确认激活后始终自动计数，缺失或冲突字段记为未知并继续监测。
- HUD、服务帧通道、地图图层、路线编辑和启动流程加入多项缓存、限流与最新帧优先优化。
- 加强 OCR 服务完整性校验、外部文件名清理和外部链接打开限制。

## Windows v0.9.4

- 童话事件改为按目标精灵记录累计触发次数，移除“80 次保底”产品逻辑；开出目标或异色不会清空累计次数。
- 血脉提升为童话页面和灵动岛的主要结果，结果展示后继续监测。
- 地图与 OCR 服务改为单文件打包，玩家目录不再包含 `_internal` 运行库、README 或嵌套压缩归档。
- OCR 单文件首次启动握手超时调整为 45 秒，兼容较慢设备的首次解包启动。

## 手机端 v0.4.4

- 将截图帧处理、定位引擎重置和追踪启停串行化到独立采集线程，修复快速启停、重新框选和服务销毁时的帧生命周期问题。
- 加强 Bitmap、ImageReader、MediaProjection 和 HUD 运行状态的回收，减少黑屏、旧帧残留和后台资源泄漏。
- 为导入路线和更新信息增加文件大小、点位及连线数量上限，异常输入会明确拒绝。
- 发布签名改为独立配置，不再把测试签名作为正式构建默认值。
- 更新下载入口仅允许带有效主机名的 HTTPS 地址，并复用通过校验的标准化链接。
- 继续提供 SIFT、模板匹配、路线导入、路线总览和四档悬浮 HUD；手机端仍不包含电脑端编辑与导出工具。

## 手机端 v0.4.3

- 修复 Android 14 及以上和部分厂商系统的 MediaProjection 全屏授权、前台服务启动顺序与横竖屏采集问题。
- HUD 尺寸扩展为紧凑、标准、中等、最大四档，地图缩放支持 `75%–300%` 并在尺寸或缩放变化后刷新视口缓存。
- 路线总览优化节点和徽标尺寸，改用稳定项目签名，并移除 14 条已废弃的内置用户路线。
- 修复采集结束、重新框选和 HUD 关闭时的帧与窗口生命周期。

## 手机端 v0.4.2

- 新增路线总览、路线方向箭头、用户路线导入和在线更新检查。
- 新增可配置灵动岛 HUD、HUD 尺寸滑杆、位置重置和路线状态显示。
- 定位模式整理为 SIFT 与模板匹配，模板匹配成为默认选项，移除混合模式。
- 小地图框选器与电脑端交互保持一致，启动追踪前必须完成有效框选。
- 增加通知栏采集/框选入口、采集授权诊断和 APK 地图、特征、路线、ABI、版本资产校验。
- HUD 地图解码、镜头平移、关键帧切换和重绘改为缓存与帧循环方案，减少周期性卡顿。

## 手机端 v0.4.1-core

- 完善路线选择、当前路线详情、HUD 状态可读性、拖动位置与位置重置。
- 增加通知栏采集控制、已保存小地图区域显示，以及框选取消、重置和回到游戏后再框选的流程。
- 启动页显示版本和当前区域，补充 APK 资产守卫与核心测试检查。

## 手机端 v0.4.0-core

- 建立手机屏幕采集和冻结帧小地图框选流程。
- 加入 SIFT 与模板匹配定位、路线导航、路线选择和可拖动悬浮 HUD。
- 手机端定位、路线与 HUD 可独立运行，不需要连接电脑；编辑器、地图标记和图片导出不在核心包中。

## Windows v0.9.3

- 修复追踪服务启动被系统策略阻止时的客户端恢复流程。
- 提高小地图框选的最小尺寸，拒绝明显过小的区域。
- 延续 v0.9.x 的多显示器物理像素区域校验、资源缓存性能优化和 S3 赛季资源。

## Windows v0.9.1

- 修复 125% / 150% 缩放和多显示器环境下合法区域被误判越界。
- 截图服务改用物理像素虚拟桌面边界，支持负坐标。
- 首次启动追踪要求在当前电脑重新框选小地图。
- 运行中重新框选后自动重启服务。
- 补充玩家包设置默认值和 S3 赛季资源目录。

## Windows v0.9.0

- **S3 赛季适配**：更新地图、地图资源、定位风险图、赛季野生异色识别模型和相关物品图标。
- **地图工具**：新增图片导出工作台和定位风险图拓展，支持点位、文字、画笔、矩形、圆形、箭头及 PNG 导出。
- **导航与 HUD**：服务停止时同步清理导航；路线文件异常时保留上一条有效路线和进度；最新帧优先显示并隔离单帧异常。
- **路线体验**：保留自定义路线名称和上次路线；路线忽略改为精确文件名匹配，并在 5 分钟后恢复推荐。
- **性能优化**：资源 JSON 后台解析，地图位图共享，资源缓存后台生成并校验版本、哈希和来源。
- **编辑与渲染**：优化资源列表虚拟化和隐藏页面刷新，资源图层改为独立 PNG 快照。
- **界面体验**：重构仪表盘、功能拓展和编辑器布局，优化侧栏与快捷功能区，并新增云端公告。
- **稳定性与安全**：修复资源缓存竞争和测绘未保存丢失；设置、路线、资源及导出文件改为原子写入。
- **环境校验**：增强截图区域、跨屏 DPI、更新链接、文件目录打开及 ONNX 工具的异常与安全检查。

- 优化 Template Match 定位逻辑，新增多尺度自动搜索机制，改善低纹理区表现。
- 修复“恢复默认”清空地图校准参数并导致路线整体偏移的问题。
- 重做灵动岛地图渲染，改善底图与玩家指针移动的流畅度。
- 修复移动时地图边缘露出黑色背景的问题。
- 修复玩家指针被路线吸附点锁定、不显示真实位置的问题。
- 提高资源底图缩放清晰度，并优化类黄色地形下的指针描边。

- 导航总览支持自动置顶且尽量不抢占游戏键盘焦点。
- 加粗放大导航总览中的路线、节点、玩家点和当前目标。
- 玩家位置、距离、锁定状态和底部状态栏改为实时刷新。
- 修复导航总览不显示玩家红点及“居中玩家”只能居中路线的问题。
- 优化客户端拖拽、导航总览加载、HUD 小地图与预览图刷新流程。
- 玩家红点改为独立动态图层，路线刷新不再影响玩家位置显示。
- 总览采用玩家状态高频更新、路线低频重绘策略。
- 修复主界面“实时轨迹视图”在部分机器上抖动的问题。
- 启动失败时写入本地日志，便于定位异常。
- 增加小地图区域快速重新框选快捷键。
- 修复候选路线清空后旧路线残留的问题。
- 客户端最小化后自动降低刷新频率。

## Windows v0.7.1

- 新增单路径 / 多路径导航模式，多路径最多选择 7 条候选路线，主路线固定参与。
- 对草地区域进行特征补强，加入游戏内标点作为稳定参照。
- 候选路线支持不同颜色，并同步到路线预览、导航总览和 HUD。
- 多路径切换改为手动确认，HUD 可确认或忽略更匹配的路线。
- 新增路线切换反馈灵动岛，分别显示切换中、成功、超时和失败。
- 新增“在此位置重新导航”快捷键 `Ctrl + Shift + F10`。
- 新增 HUD 视觉平滑开关。
- 优化候选路线异步加载和导航总览刷新策略。
- HUD 加入 mipmap 渲染缓存，移动时优先使用低分辨率图层裁剪。
- 缓存路线段并复用每帧枚举结果，减少对象分配、GC 和重复计算。
- 多路径建议加入候选缓存，玩家移动不足一定距离时复用结果。
- 玩家坐标变化时只刷新视口和玩家点，不再重建全部 HUD 文本及动画。
- 平滑居中刷新加入最小间隔，地图面板隐藏时停止刷新。
- 缓存并冻结固定颜色画刷，减少 UI 线程分配。
- 服务端对预览图和小地图图片进行产出节流，降低 Base64 编码、JSON 传输和客户端解析压力。
- 修复候选路线关闭后 HUD 残留、路线切换写入失败后状态不一致及路线元数据缓存刷新不及时的问题。

## Windows v0.5.0

- 引入 ORB 算法以尝试改善草地区域抖动并降低 CPU 占用；该算法已在后续版本移除。
- 设置页按追踪算法切换对应参数页面。
- 小地图输入链统一为圆形有效区域。
- 路线编辑器支持节点类型、分支起点、线工具悬停预高亮、单点拖动及传送点浅蓝虚线。
- 路线文件优先读取 `nodes + edges`，继续兼容旧版 `points` 并转换为内部边结构。
- 资源点编辑器支持按分类和物品图标新增、拖动、删除、撤销、保存与导出。
- 资源点层从逐点控件改为单层集中绘制，改善大量资源点时的编辑流畅度。
