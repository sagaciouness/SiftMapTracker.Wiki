# 童话事件与血脉

童话事件模块监测“四叶草铅绘”事件，识别每次开出的精灵与血脉，并按目标精灵保存累计触发次数。累计次数只用于个人记录，不代表游戏保底。

![童话事件页面](/screenshots/v0.9.3/screen-recognition-fairy-events.png)

## 开始监测

1. 在“目标精灵”中按名称、别名或 ID 搜索。
2. 选中目标并点击“选择为目标”。
3. 打开“采集校准 → 童话事件”，框选名称区和结果横幅区。
4. 返回童话事件页，点击“开始监测”或按 `Alt + T`。

成功开始后，地图追踪会停止并复位地图 HUD。暂停童话监测后，地图追踪不会自动重新启动。

## 两个采集区域

- **右上角目标名称区域**：覆盖完整名称；等级、血量可以保留，但不要包含大面积背景。
- **结果横幅区域**：粗框横幅的大致范围即可，不必紧贴文字；尽量覆盖完整血脉句子，并确保“发现异色精灵！”提示位于区域内。程序会在选区周围自动寻找橙色高亮血脉词，提高轻微偏框时的容错。

监测期间只持续读取名称小区域。检测到“四叶草铅绘”后会提高采集频率并开始观察横幅，事件进入结果阶段后同时读取名称区和横幅区。

## 状态流程

```text
童话待命
→ 正在监测
→ 正在确认四叶草铅绘
→ 童话事件已激活
→ 正在读取事件结果
→ 已自动记录 / 错误
```

“四叶草铅绘”需要两次独立、可靠的 OCR 确认。确认激活后，本次事件一定会自动计入累计次数；事件结果会继续合并名称与横幅证据，以降低动画、遮挡和短暂误识别的影响。血脉达到现有置信度门槛且无冲突时，会立即成为页面主结果；客户端仍会在现有结果窗口内尝试补全精灵名称。

结果窗口结束时，可靠字段按识别结果保存，缺失、置信度不足或证据冲突的字段记为未知。即使精灵和血脉都无法可靠识别，事件也会以“未知精灵 + 未识别血脉”自动落账并继续监测，不需要玩家确认或作废。

## 累计触发次数

- 每个目标精灵分别保存累计触发次数；
- “四叶草铅绘”经双帧确认激活后累计次数 `+1`，结果字段是否完整不影响计数；
- 开出目标精灵或识别到异色提示时，累计次数不会清零；
- 完成结果展示后会继续监测，不因次数或血脉自动暂停；
- 切换目标前会暂停监测；重新选回旧目标时恢复该目标的累计记录；
- `+1`、`−1` 和“重置”用于人工校正，都会写入审计记录；
- 从旧版本升级时，原有轮次记录会自动迁移为累计次数。

::: info 计数用途
累计触发次数是本地统计信息，没有 `80` 次上限，也不用于推断或承诺游戏内保底。
:::

## 血脉识别

血脉是童话页面和灵动岛的主要结果。页面会突出显示最近血脉，并保留累计血脉分布、结果精灵和事件历史。

从 `0.9.7` 起，血脉识别优先从横幅附近提取橙色高亮词，并只在“奇异、污染、混乱、异色”四种结果中做严格匹配。快路径需要连续两次得到一致结果；如果没有唯一可靠结果，程序才会回到原始横幅选区识别完整句子。完整且高置信的血脉句子或“发现异色精灵！”提示可以直接作为强证据。

| 血脉 | 识别内容 |
| --- | --- |
| 奇异 | “染上了几笔奇异的颜色” |
| 污染 | “染上了几笔污染的颜色” |
| 混乱 | “染上了几笔混乱的颜色” |
| 异色 | “染上了几笔异色的颜色” |
| 未识别 | 结果窗口内没有可靠血脉，或血脉证据发生冲突 |

可靠血脉一经识别即可作为主要结果：即使结果精灵始终无法确认，也会保存为“未知结果 + 已识别血脉”。只有可靠精灵时保存精灵并将血脉记为“未识别”；精灵名称冲突时精灵记为未知，两个不同的可靠血脉发生冲突时血脉记为“未识别”。程序不会根据单帧噪声或不唯一候选猜测血脉，这些情况仍会自动累计一次并继续监测。

当横幅以足够置信度识别到 **“发现异色精灵！”** 时，该提示具有更高优先级：

1. 当前事件只记录一次；
2. 血脉直接记为“异色”；
3. 同帧能识别结果名称时保存精灵，否则记录“未知异色”；
4. 累计触发次数 `+1`；
5. 结果展示结束后继续监测。

普通的“染上了几笔异色的颜色”只表示血脉，不会改变累计计数规则。

## 灵动岛显示

- 待命时显示紧凑的圆角矩形状态；
- 监测时显示目标精灵和累计触发次数；
- 首次可靠识别到血脉时，岛下方立即展开一次独立提示条，显示“识别到混乱血脉”等结果和 OCR 置信度，约 4 秒后收起；
- 同一事件的重复 OCR 不会刷新提示动画，下一个事件仍可再次提示；
- 事件结算后以“奇异血脉”“混乱血脉”等作为主标题；
- 没有可靠血脉时显示“童话事件已自动记录”，未知字段只作为识别质量提示；
- 结果精灵和累计次数作为辅助信息保留；
- 完成提示约 8 秒后自动恢复监测状态；
- “设置 → 灵动岛 → 边缘黑框透明度”同时作用于地图、查蛋和童话状态，状态切换不会恢复固定不透明背景。

## 中断恢复与记录质量

客户端在已确认事件尚未落账时退出或中断，会保留未完成事件：

- 恢复后仍显示激活画面时继续采集；
- 已进入结果画面时继续正常的结果读取窗口；
- 无法恢复连续画面证据时，以未知结果自动落账一次。

历史会以只读质量状态区分“完整”“识别不完整”“结果冲突”和“中断恢复”。不存在待复核阻塞、人工计入或人工作废；同一事件通过事件 ID 防止重复累计。

::: info 本轮识别范围
童话事件目前只识别结果精灵、血脉和权威异色提示，不包含“特长”有无识别，也不需要额外框选第三个区域。
:::
