# 自动手碟

把 MIDI 曲子转换成游戏手碟能弹的九个音，先试听、修改，再向你选择的游戏窗口发送按键。软件窗口标题为“自动化手碟”，程序文件名是 `SiftHandpanWorkbench.exe`。

这是**独立的 Windows 电脑工具**，不是 SIFT 地图追踪客户端里的功能，不需要安装地图、Python 或启动追踪服务。

::: danger 使用前先看
脚本鼠标宏原理，注意封号风险，本项目仅供学习参考。不保证游戏允许或接受自动按键。安装驱动会影响系统输入环境，独立软件不能隔离驱动影响；不愿承担风险时，请只使用本地试听。
:::

## 能做什么

![自动手碟当前界面，以内置示例展示导入、编辑、试听和选择游戏的位置](/screenshots/handpan/workbench.png)

- 导入 MIDI，选择要弹的部分，也可以直接输入键谱。
- 试听、调整速度，移动和裁剪片段，修改音符。
- 保存曲谱，导出 MIDI 或键谱。
- 在本地测试窗口检查按键，再自行验证游戏是否响应。

游戏手碟只有 B、F、G、H、J、K、T、Y、U 九个按键，不能完整还原任意钢琴曲或和弦。曲子里弹不了的音可能被跳过；只有主动勾选后，才会尝试换成相近的音。
