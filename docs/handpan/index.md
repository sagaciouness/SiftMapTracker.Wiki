# 自动手碟

导入 MIDI，试听并调整曲谱，选好游戏窗口后就可以开始演奏。也可以从[地图工坊曲库](https://www.mapforge.top/scores)下载手碟版 MIDI。

自动手碟是 Windows 独立软件，解压后打开 `SiftHandpanWorkbench.exe` 即可，无需安装 SIFT 客户端或 Python。

::: warning 使用提醒
自动演奏通过驱动发送键盘按键，有封号风险，请自行了解游戏规则。驱动安装后会影响系统输入；只想看谱或试听，可以不安装驱动。
:::

## 从这里开始

- [快速开始](./quick-start)：下载软件、安装驱动、选择键盘和游戏窗口。
- [手碟曲库](https://www.mapforge.top/scores)：找曲子、看谱、下载 MIDI。软件右上角的“下载乐谱”也能打开曲库。
- [驱动安装与卸载](./driver)：首次安装或不再使用时查看。
- [导入歌曲与修改曲谱](./songs)：导入自己的 MIDI，调整音符和播放速度。
- [常见问题](./troubleshooting)：找不到键盘、游戏没反应、演奏暂停等问题。

## 能做什么

![自动手碟当前界面，以内置示例展示导入、编辑、试听和选择游戏的位置](/screenshots/handpan/workbench.png)

- 导入 MIDI，选择要弹的部分，也可以直接输入键谱。
- 试听、调整速度，移动和裁剪片段，修改音符。
- 保存曲谱，导出 MIDI 或键谱。
- 用测试窗口检查按键，再切到游戏演奏。

游戏手碟只有 B、F、G、H、J、K、T、Y、U 九个按键，部分歌曲转换后会缺音或与原曲不同。默认跳过超出音域的音符；勾选“不能弹的音换成相近音”后，可以尝试用相近音替代。
