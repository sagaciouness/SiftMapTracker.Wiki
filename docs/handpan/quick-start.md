# 五分钟快速开始

本教程适用于自动手碟 **0.1.6**（Windows x64）。已安装驱动的用户可以从第 3 步开始。

## 1. 下载并打开软件

在[作者发布页](https://space.bilibili.com/1570010855)查看下载说明，下载 Windows x64 便携包。完整解压后，打开 `SiftHandpanWorkbench.exe`，保留同目录下的 `Input` 等文件夹。

## 2. 首次安装驱动，重启电脑

按[驱动安装教程](./driver#安装与重启)安装 Interception，完成后**重启电脑**，再打开自动手碟。驱动只需安装一次；看谱和试听不需要驱动。

## 3. 下载一首曲子，导入并试听

1. 点击软件右上角绿色的 **下载乐谱**，打开[地图工坊手碟曲库](https://www.mapforge.top/scores)。
2. 找到想弹的曲子，在详情页下载 **手碟版 MIDI**。只有文字谱的作品可以照着手弹。
3. 回到软件，点击 **新建 → 导入 MIDI**，选择下载的文件。
4. 在弹出的列表中选择要导入的部分，点击 **导入选中项**。主旋律和伴奏可以一起导入：按住 **Ctrl** 点击可多选，按住 **Shift** 可连续选择。
5. 点击 **试听**，确认曲子后点 **停止**。

不同按键可以同时演奏。如果提示“同键重复过快”，点击 **查看问题**，降低播放速度或调整标出的音符，详见[曲谱编辑](./songs)。

## 4. 查找并选择键盘

点击下方 **查找键盘**，在旁边的列表中选择键盘。

列表里有多个键盘时，可以逐个测试：点 **测试按键**，再点 **开始演奏**，在 5 秒内切到测试窗口。音垫随曲子亮起，说明这个选项可用。测试结束后点 **停止**，再选择游戏窗口。

## 5. 选择游戏，开始演奏

1. 打开游戏，进入**手碟演奏界面**，手动按一下 **H**，确认能发声。
2. 回到软件，点击 **刷新窗口**，在 **选择游戏** 中选中游戏窗口。
3. 点击 **开始演奏**，在 **5 秒内切回游戏**，松开 Ctrl、Alt、Shift 等键，等待演奏。

默认快捷键：**Ctrl+Alt+F11 暂停 / 继续**，**Ctrl+Alt+F12 停止**。切出游戏会暂停；继续时有新的倒计时，记得切回游戏。

想保留这首曲子的编辑结果，点击 **保存**；下次用 **打开曲谱** 继续使用。
