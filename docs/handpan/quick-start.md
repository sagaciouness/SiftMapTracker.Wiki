# 五分钟快速开始

适用：自动手碟 **0.1.6**，Windows x64。第一次使用需要安装驱动并重启；已安装的可以直接从第 3 步开始。

## 1. 下载并打开软件

从[作者发布渠道](https://space.bilibili.com/1570010855)的配套说明下载自动手碟 Windows x64 便携包，将整个压缩包解压到一个文件夹，再打开 **`SiftHandpanWorkbench.exe`**。保留旁边的 `Input` 等文件夹。

## 2. 首次安装驱动，重启电脑

按[驱动安装教程](./driver#安装与重启)安装 Interception，成功后**重启电脑**，再打开自动手碟。这个步骤只需首次安装时完成；只看谱或试听可以跳过。

## 3. 下载一首曲子，导入并试听

1. 点击软件右上角绿色的 **下载乐谱**，打开[地图工坊手碟曲库](https://www.mapforge.top/scores)。
2. 找到想弹的曲子，在详情页下载 **手碟版 MIDI**。只有文字谱的作品可以照着手弹。
3. 回到软件，点击 **新建 → 导入 MIDI**，选择下载的文件。
4. 在弹出的列表中选择要导入的部分，点击 **导入选中项**。主旋律和伴奏可以一起导入：按住 **Ctrl** 点击可多选，按住 **Shift** 可连续选择。
5. 点击 **试听**，确认曲子后点 **停止**。

0.1.6 支持多轨和弦，**不同按键可以同时演奏**。如果提示“同键重复过快”，点击 **查看问题** 定位，再降低播放速度或调整对应音符。详细编辑方法见[导入歌曲与修改曲谱](./songs)。

## 4. 查找并选择键盘

点击下方 **查找键盘**，在旁边的列表中选择键盘。

如果有多个选项、不确定该选哪个，可以点 **测试按键**，再点 **开始演奏**，在 5 秒内切到测试窗口。音垫随曲子亮起，说明该选项能发送按键。测试结束后点 **停止**，继续下一步选择游戏。

## 5. 选择游戏，开始演奏

1. 打开游戏，进入**手碟演奏界面**，手动按一下 **H**，确认能发声。
2. 回到软件，点击 **刷新窗口**，在 **选择游戏** 中选中游戏窗口。
3. 点击 **开始演奏**，在 **5 秒内切回游戏**，松开 Ctrl、Alt、Shift 等键，等待演奏。

默认快捷键：**Ctrl+Alt+F11 暂停 / 继续**，**Ctrl+Alt+F12 停止**。切出游戏会暂停；继续时有新的倒计时，记得切回游戏。

想保留这首曲子的编辑结果，点击 **保存**；下次用 **打开曲谱** 继续使用。
