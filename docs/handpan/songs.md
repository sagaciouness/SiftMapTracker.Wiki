# 导入歌曲与修改曲谱

适用：独立自动手碟 0.1.5（2026-09-19 界面）。先完成[快速开始](./quick-start)里的短示例测试，再换自己的曲子。

## 从手碟曲库下载

点击软件右上角绿色的 **下载乐谱**，会打开地图工坊的[手碟曲库](https://www.mapforge.top/scores)。找到曲子后可以先看按键谱和作品说明；作者提供 MIDI 时，下载后回到软件点击 **导入 MIDI**。只有按键谱的作品可以直接照着手弹，或将带时值的键谱复制到 **键谱 / 示例** 中载入。

下载的 MIDI 仍需选择旋律声部并试听。别人分享的曲子不一定适合当前速度，也不代表已经在你的游戏环境中验证过。

## 第一次只选主旋律

1. 准备 `.mid` 或 `.midi` 文件。MP3、WAV、视频不能直接导入，本工具不提供听歌扒谱功能。
2. 点“新建”，处理好旧曲谱的保存提示，再点“导入 MIDI”。
3. 在弹出的列表选择要弹的部分。第一次先选一个主旋律部分；通常默认不列入打击乐通道，不要一开始全选钢琴伴奏。
4. 导入后点“试听”。程序会选择较合适的按键，但九音手碟不能完整还原所有歌曲；原曲的停顿和速度变化会保留。
5. 不满意时换一个部分试试。继续导入会增加曲目和片段，并非自动替换旧曲子；不想叠加时请先新建。

同一部分里同时响起的多个音，导入时按单旋律处理并取最高音。不要把它当成完整钢琴伴奏的还原工具。

## 弹不了的音怎么办

选中一个片段，右侧会显示可弹音符数量。不能对应九音的音符会保留在原来的时间位置，不会把后面的节奏往前挤。

- 可以手动给这些音符指定按键。
- 可以勾选“不能弹的音换成相近音”，再点“重新转换”，但这样会改变部分音高，先试听再决定。
- 重新转换会替换手工改过的音符，软件会询问确认；可以用“撤销”退回。

## 曲子太密或听起来乱

多个片段同时弹，或者相邻按键间隔太短，可能出现问题提示。这时点“查看问题”定位，不要反复按“开始演奏”。

1. 先只保留一个主旋律音轨，或用“静音”“只播这轨”检查。
2. 对于间隔太短的音符，降低右侧“播放速度”，点“确认设置”，再检查。
3. 对于完全重叠的音符，单纯降速不能解决，需要移动、删除或静音其中一部分。

有冲突的整曲演奏和成品导出会被阻止，但仍可保存曲谱、编辑或试听选中的单个片段进行排查。

“节拍参考（BPM）”用于网格与键谱换算，**不会改变导入 MIDI 的原速度**。想让整首慢一点，请调整“播放速度”；`1` 为原速，`0.5` 为半速。

## 简单编辑

- 点中片段后拖动，可以调整开始位置；拖动左右边缘裁剪，不会自动变速。
- 选择片段，定位到要分开的位置，点“切分”。
- 下方是选中片段的音符。双击空白添加音符，拖动改变时间或按键；右侧可精确修改时间和力度。
- “自动对齐”方便拖动时对齐时间格，关闭后可以自由移动。
- “撤销”或 Ctrl+Z 可退回上一步，Ctrl+Y 重做。试听或演奏时先停止，再改曲谱。

## 保存与导出有什么区别

- **保存 / 另存为**：保存 `.handpan.json`，包含可继续编辑的曲谱与素材。下次用“打开曲谱”打开，不依赖原 MIDI 仍在原位置。
- **导出 MIDI**：输出转换后的曲子，不是原始完整伴奏；速度采用当前播放设置。
- **导出键谱**：输出按键和时长，文件内会注明 BPM，重新使用时注意该数值。

曲谱不会自动替你恢复上次的键盘和游戏目标；重新打开软件后请再次选择。

## 不用 MIDI，也能输入键谱

点“键谱 / 示例”，例如输入生日快乐前两句：

```text
H:0.75 H:0.25 J H T K:2 | H:0.75 H:0.25 J H Y T:2
```

连续字母如 `HHJHTK` 会逐音解析，默认每音一拍；`H:0.5` 是半拍，`-:1` 休止一拍，`|` 只是分隔符。键谱时长由输入时的 BPM 换算，别把没有节奏标注的一串字母当作原曲完整节奏。
