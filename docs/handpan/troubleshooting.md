# 常见问题

适用：自动手碟 0.1.6 与官方 Interception v1.0.1。

## 驱动装不上或查找不到键盘

先检查下载文件、安装路径和管理员权限，以及安装后是否重启：

1. 确认下载的是官方 `Interception.zip`，安装器位于 `command line installer`。
2. 依照[驱动安装教程](./driver#安装与重启)检查 `Test-Path` 是否为 `True`，并在管理员 PowerShell 中安装。
3. 成功后重启电脑。重新插拔键盘后再次查找。
4. 如果系统阻止驱动，停止尝试，记录完整提示。不要关闭系统安全保护或安装不明替代驱动。

仍未解决时，反馈 Windows 版本、驱动下载地址、完整安装提示、是否重启，以及“查找键盘”后的提示。

## 提示缺少 interception.dll

通常是压缩包没解压完整、只复制了 EXE，或文件被安全软件隔离。检查软件目录下的 `Input/Interception/x64/interception.dll`，缺失时重新完整解压软件包。不要单独从 DLL 下载站补文件，也不用复制到 System32。若被安全软件拦截，请先查看并保留拦截原因。

仍有问题时提供提示原文和软件目录结构截图，隐藏个人路径信息。

## 列表里出现好几个键盘

同一个键盘可能显示多个设备接口。可以逐项选择，再用“测试按键”窗口播放九键示例，找到能正常响应的选项。

插拔设备、有线与无线模式切换后，请重新查找。如果仍不确定，反馈键盘型号、连接方式和列表里的 VID/PID 信息；无需提供设备序列号。

## 测试窗口正常，游戏没有反应

测试窗口和游戏的输入方式可能不同，可以依次检查：

1. 游戏是否在真正的手碟演奏界面，手动按 H 是否发声？
2. “选择游戏”是否选中游戏本身，而不是启动器、测试窗口或已失效的旧窗口？
3. 五秒倒计时结束前，是否已切回游戏并松开 Ctrl、Alt、Shift、Windows 键？
4. 游戏窗口或进程重启后，是否重新刷新并选择？

以上都正常但游戏仍没反应，可能是游戏输入限制或兼容性问题。先停止测试，保留对应日志。

反馈时说明驱动是否安装成功、能否找到键盘、测试窗口和游戏各自的表现，并附日志。游戏内请在手碟演奏界面测试。

## 一切回软件就暂停

切出游戏或按住 Ctrl、Alt、Shift 等修饰键时，软件会暂停并尝试松开按键。切回游戏后需要手动继续。

按 Ctrl+Alt+F11 继续，松开组合键，在倒计时结束前切回游戏。按 Ctrl+Alt+F12 停止演奏。反复暂停时，请记录状态提示和当时的操作顺序。

## 不能开始，提示停止快捷键不可用

快捷键可能被其他软件占用。进入“设置 → 紧急停止快捷键”，换一个组合键，等窗口底部显示可用后再试。停止快捷键不可用时，软件无法开始自动演奏。

## 显示音符重叠或太密

0.1.6 支持不同按键同时起音，同一时刻的同键音会自动合并。如果提示“同键重复过快”，点 **查看问题** 定位，降低播放速度或调整对应重复音符，也可以用 **静音 / 只播这轨** 排查。详见[曲谱调整](./songs)。仍不清楚时提供相关片段截图、软件版本、播放速度、按键时长与间隔。

## 按键像卡住了，或提示释放失败

先停止演奏，手动按下再松开提示中的键。若仍卡住，检查设备连接，保留错误提示，必要时保存工作并重启电脑。驱动异常时，软件可能无法正常松开按键；若系统输入也受影响，可按[驱动卸载步骤](./driver#不用了怎么卸载)处理。

## 日志在哪里

在“帮助”菜单点“打开独立日志目录”，取出发生问题当天的日志，保留出错前后的完整时间段。也可以在文件资源管理器地址栏输入 `%LocalAppData%\SiftHandpanWorkbench\logs`。

反馈时附上软件版本或下载日期，遮挡日志和截图中的用户名、私人路径及无关聊天内容，只发送与问题有关的文件。
