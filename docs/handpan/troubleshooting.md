# 常见问题

适用：独立自动手碟 0.1.0（2026-09-18 界面）与官方 Interception v1.0.1。先把问题分清：软件能打开、声音正常、驱动能用、游戏响应，是不同环节。

## 驱动装不上或查找不到键盘

**现象：**安装报错，或点“查找键盘”没有可选设备。

**可能原因：**下载了源码、路径不对、没有管理员权限、尚未重启，或系统不允许驱动加载。

**处理：**

1. 确认下载的是官方 `Interception.zip`，安装器位于 `command line installer`。
2. 依照[快速开始](./quick-start)检查 `Test-Path` 是否为 `True`，并在管理员 PowerShell 中安装。
3. 成功后重启电脑。重新插拔键盘后再次查找。
4. 如果系统阻止驱动，停止尝试，记录完整提示。不要关闭系统安全保护或安装不明替代驱动。

**仍不成功：**提供 Windows 版本、驱动下载来源、安装输出、是否已重启，以及“查找键盘”后的提示。不要只截最后一行。

## 提示缺少 interception.dll

通常是软件包未完整解压、只复制了 EXE，或文件被安全软件处理。先检查软件目录内是否有 `Input/Interception/x64/interception.dll`，再从可信的软件包重新完整解压；不要去 DLL 下载站碰运气，不要复制到 System32。若安全软件拦截，请保留原因并停止，不要直接关闭防护。

仍有问题时提供提示原文和软件目录结构截图，隐藏个人路径信息。

## 列表里出现好几个键盘

这些是设备接口，不是多套驱动；同一个设备可能占多项。先在“测试按键”窗口逐项确认，选中后测试完整的九键示例。不要假定“键盘 1”就是正在使用的物理键盘。

插拔设备、有线与无线模式切换后，请重新查找。如果仍不确定，反馈键盘型号、连接方式和列表里的 VID/PID 信息；无需提供设备序列号。

## 测试窗口正常，游戏没有反应

这说明本地测试窗口可以收到自动按键，**不能据此保证游戏接受**。请按以下顺序检查：

1. 游戏是否在真正的手碟演奏界面，手动按 H 是否发声？
2. “选择游戏”是否选中游戏本身，而不是启动器、测试窗口或已失效的旧窗口？
3. 五秒倒计时结束前，是否已切回游戏并松开 Ctrl、Alt、Shift、Windows 键？
4. 游戏窗口或进程重启后，是否重新刷新并选择？

如果手动按键和本地自动测试正常，但游戏始终不响应，应停止测试：可能是游戏输入限制或兼容性问题。没有保证有效的处理办法；本教程不提供关闭保护或绕过游戏限制的方法。

反馈时分开说明“安装是否成功 / 重启后是否检测到键盘 / 测试窗口是否收齐按下和松开 / 游戏是否响应”，并附对应时间段日志。聊天框测试不能替代手碟界面测试。

## 一切回软件就暂停

这是保护机制。目标失去前台，或按着修饰键时会暂停并尝试松开按键。切回游戏不会自动恢复。

使用默认 Ctrl+Alt+F11 继续后，松开组合键，并在新倒计时结束前切回选定窗口。要结束，按 Ctrl+Alt+F12。持续暂停时提供当时的状态文字和操作顺序，不要关闭失焦保护。

## 不能开始，提示停止快捷键不可用

可能被其他软件占用。进入“设置 → 紧急停止快捷键”，换一个未占用的组合键，确认窗口底部显示可用，再测试。软件会在没有可用停止快捷键时禁止自动按键，不应跳过该检查。

## 显示音符重叠或太密

点“查看问题”定位。先取消不需要的伴奏轨道，解决完全重叠的音，再适当降低播放速度；仅降速不能解决同时起音。详见[曲谱调整](./songs)。仍不清楚时提供相关片段截图、播放速度、按键时长与间隔。

## 按键像卡住了，或提示释放失败

立即停止演奏，手动按下再松开提示中的键。停止、关闭等路径都会尝试释放按键，但驱动异常时不能保证成功。不要继续发送，也不要反复重装；先检查设备并保存错误信息。必要时保存工作后重启。若系统输入受影响，参照[官方驱动卸载](./driver#不用了怎么卸载)处理。

## 日志在哪里

在“帮助”菜单点“打开独立日志目录”，取出发生问题当天的日志，保留出错前后的完整时间段。也可以在文件资源管理器地址栏输入 `%LocalAppData%\SiftHandpanWorkbench\logs`。

反馈前遮挡用户名、私人文件路径和无关聊天内容，不要上传整个用户目录、游戏包体或设备隐私信息。未解决的问题请同时说明软件包日期；旧版本按钮和行为可能不同。
