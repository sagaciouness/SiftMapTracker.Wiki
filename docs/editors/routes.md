# 路线编辑

路线编辑器只用于建立导航节点和节点之间的连线。用途、单/多路径模式、路线候选以及开始/停止操作已移至侧栏“开始导航”页。多路径模式下，绘图区会提示切换为单路径模式。

## 基本流程

1. 在“开始导航”选择“单路径导航”，再打开“路线编辑”。
2. 点击“新建路径”并填写名称，或选择要修改的路线。
3. 点击“开始绘制”，用“点工具”放置节点，用“线工具”按行进顺序连线。路线经过传送位置时，可设为“传送点”。
4. 绘制完成后点击“结束绘制”，用“保存路线”保存。要分享给其他玩家，使用“路径导出”。
5. 回到“开始导航”选中该路线，确认起点和行进方向，再开始导航。

## 编辑规则

- 路线名称来自 JSON 内的 `name`，查看文件不应自动改成文件名。
- 节点坐标使用 8192 地图坐标系，与显示地图、资源点和测绘工具一致。
- 保存采用同目录临时文件和原子替换，避免服务恰好读取到半写入 JSON。
- 删除路线编辑器中的路线文件前应先备份；普通“删除图层”不会删除原始路线文件。

## 分享前检查

- 路线名称和说明不包含私人信息；
- 起点附近能够成功吸附；
- 每个节点均有合理连线；
- 闭环路线的尾节点能回到起点；
- 在实际游戏中完整运行至少一圈。

可在 [MapForge](https://www.mapforge.top/packs) 下载或分享路线。
