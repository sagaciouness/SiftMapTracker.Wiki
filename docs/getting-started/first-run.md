# 首次启动

## 算法选择

首次启动会要求选择定位算法：

- **SIFT**：默认推荐，地标和纹理较丰富时稳定性最好。
- **模板匹配（TM）**：适合固定比例和较清晰的小地图，但对缩放、旋转和重复纹理更敏感。

选择结果可在设置页修改，重新启动追踪服务后生效。

## 首次框选

首次启动追踪前必须在当前电脑上框选小地图。项目不会沿用开发者电脑的截图坐标。

框选时：

- 保留小地图的完整圆形或方形内容；
- 不要框入地图外的任务列表和按钮；
- 宽和高均不得低于 `158px`；
- 在多显示器环境中，将鼠标放到游戏所在屏幕再打开框选器。

开始框选前，客户端会暂时隐藏当前进程的主窗口、HUD、灵动岛和预览窗口，完成、取消或发生异常后再恢复原状态。框选背景采用聚光遮罩：选区内部保持原亮度，外围变暗，并显示绿色边框和小地图圆形参考线。

松开鼠标后可用滚轮缩放选区、左键拖动位置，按 `Enter` 确认，按 `Esc` 取消。取消不会覆盖旧区域；追踪正在运行时，框选期间服务不会提前停止，只有成功保存新区域后才会重启。

## SIFT 小尺寸缓存

SIFT 直接按选区短边选择缓存，不再等待识别小地图圆：

| 选区短边 | SIFT 档位 |
| --- | --- |
| `158–163px` | 动态 160 |
| `164–192px` | 紧凑 165 |
| `193px` 及以上 | 标准 220 |

选择 `158–163px` 时会先显示“生成并使用当前尺寸 / 自行调整分辨率”。生成需要至少 4 GB 可用物理内存和 256 MB 可用磁盘空间；已有有效缓存时会直接复用。选择调整分辨率、关闭或取消时不会保存新选区。

## 如何判断成功

满足以下条件即可认为首次配置有效：

1. 预览窗口能持续显示小地图。
2. 服务状态为运行中。
3. 日志没有持续出现 Capture、OpenCV 或特征文件错误。
4. 在有明显道路和建筑的区域移动时，坐标和 HUD 指针随之更新。
