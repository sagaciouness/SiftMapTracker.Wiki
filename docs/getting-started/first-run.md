# 首次启动

## 算法选择

首次启动会要求选择定位算法：

- **SIFT**：默认推荐，地标和纹理较丰富时稳定性最好。
- **模板匹配（TM）**：适合固定比例和较清晰的小地图，但对缩放、旋转和重复纹理更敏感。

选择结果可在设置页修改，重新启动追踪服务后生效。

## 首次框选

首次启动追踪前必须在当前电脑上框选小地图。项目不会沿用开发者电脑的截图坐标。

框选时：

- 保留小地图的完整圆形或方形内容；
- 不要框入地图外的任务列表和按钮；
- 宽和高均不得低于 `135px`；
- 在多显示器环境中，将鼠标放到游戏所在屏幕再打开框选器。

开始框选前，客户端会暂时隐藏当前进程的主窗口、HUD、灵动岛和预览窗口，完成、取消或发生异常后再恢复原状态。框选背景采用聚光遮罩：选区内部保持原亮度，外围变暗，并显示绿色边框和小地图圆形参考线。

松开鼠标后可用滚轮缩放选区、左键拖动位置，按 `Enter` 确认，按 `Esc` 取消。在框选器中按 `Esc` 会保留原区域。按 `Enter` 确认后会保存新区域；即使随后取消生成缓存，下次启动追踪也可以沿用这次框选。

## SIFT 缓存档位

SIFT 直接按选区短边选择缓存，不再等待识别小地图圆：

| 选区短边 | SIFT 档位 |
| --- | --- |
| `135–139px` | 动态 136 |
| `140–147px` | 动态 144 |
| `148–157px` | 动态 152 |
| `158–163px` | 动态 160 |
| `164–192px` | 紧凑 165 |
| `193–256px` | 标准 220 |
| `257–512px` | 16px 间隔动态大尺寸档 |
| `>512px` | 不支持 |

选区有可用缓存时会直接复用。首次使用动态档，选择“生成并使用当前尺寸”并等待完成。若提示内存不足，可稍后再试，也可调整游戏分辨率后重新框选。内存和磁盘预留量随选区尺寸变化，见[算法与参数](/tracking/algorithms)。

## 如何判断成功

满足以下条件即可认为首次配置有效：

1. 预览窗口能持续显示小地图。
2. 服务状态为运行中。
3. 日志没有持续出现 Capture、OpenCV 或特征文件错误。
4. 在有明显道路和建筑的区域移动时，坐标和 HUD 指针随之更新。
