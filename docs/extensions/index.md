# 功能拓展

功能拓展页提供不属于核心实时定位链路的附加能力。关闭拓展后，不应增加追踪负担。

![功能拓展页](/screenshots/v0.9.3/extensions-overview.png)

## 野生标记检测

从小地图中检测野生黑白、异色、炫彩及其组合标记，经过连续帧确认后播放提示音并显示通知。检测状态在每次启用时重新开始，手动采集不会继承上一次候选帧数。

### 候选诊断

遇到普通地图图标被误报时，可在野生检测的高级设置中临时开启“保存候选诊断”。诊断默认关闭，开启并重启追踪后才会保存：

- 只保存分数达到 `0.70` 的候选小裁剪、类别分数和模型信息，不保存完整屏幕；
- 诊断目录最多使用 `200 MB`，超过上限会优先删除最旧文件；
- “打开目录”可直接查看反馈文件，“清理”只删除野生检测诊断目录；
- 候选若越过小地图边界、需要补纯黑像素，会在进入模型前被忽略；目标完整进入小地图后仍可正常识别。

反馈完成后建议关闭诊断，避免持续产生文件。当前模型没有真实正样本集，发布闸门中的召回率来自固定种子的严格合成回归；玩家提供的误报小裁剪作为真实硬负样本单独验证。

## 地图标记

打开独立的标记与导出工作台，将当前路线、资源缓存和玩家标记组合为图层。详见[地图标记](/editors/survey-map)。

## 定位风险图

查看开发阶段离线生成的静态 SIFT/TM 可定位性估算，不会在玩家电脑上运行额外分析。详见[定位风险图](/extensions/localization-risk)。
