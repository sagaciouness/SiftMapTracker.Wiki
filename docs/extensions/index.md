# 功能拓展

功能拓展页提供不属于核心实时定位链路的附加能力。关闭拓展后，不应增加追踪负担。

![功能拓展页](/screenshots/v0.10.6/extensions-overview.png)

## 野生炫彩检测

在“功能拓展”打开“野生炫彩检测”。追踪运行时，软件会在游戏小地图中检测野生炫彩、黑白和异色图标，命中后通过灵动岛提醒。要先听提示音，勾选“提示音”，调整音量并点击旁边的播放按钮。

若游戏运行吃紧，可展开“高级性能设置”，把性能模式从“标准”改为“省资源”。

### 候选诊断

遇到普通地图图标被误报时，可在野生检测的高级设置中临时开启“保存候选诊断”。诊断默认关闭，开启并重启追踪后才会保存：

- 只保存分数达到 `0.70` 的候选小裁剪、类别分数和模型信息，不保存完整屏幕；
- 诊断目录最多使用 `200 MB`，超过上限会优先删除最旧文件；
- “打开目录”可直接查看反馈文件，“清理”只删除野生检测诊断目录；
- 候选若越过小地图边界、需要补纯黑像素，会在进入模型前被忽略；目标完整进入小地图后仍可正常识别。

反馈完成后可关闭“保存候选诊断”。

## 自由测绘

点击“自由测绘”卡片的“打开”，即可标注地图并导出 PNG。见[地图标记](/editors/survey-map)。

## 定位风险图

点击“定位风险图”卡片的“打开”，可预先查看路线哪些地方更容易丢失定位。见[颜色图例与地图操作](/extensions/localization-risk)。
