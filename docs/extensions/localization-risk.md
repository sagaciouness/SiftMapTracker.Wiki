# 定位风险图

打开“功能拓展”，点击“定位风险图”卡片的“打开”。用滚轮放大准备经过的区域，再拖动右侧“透明度”滑杆，对照底图辨认道路和地标。

![S3 静态定位风险图](/screenshots/v0.10.6/localization-risk-map.png)

## 颜色含义

- 绿色：特征和纹理较丰富，通常较稳定；
- 黄色：需要注意，遮挡或缩放变化可能影响结果；
- 橙色：较高风险；
- 红色：高风险，常见于大面积草地、雪地、海面或重复纹理。

## 操作

- 在右侧“图层”勾选或取消“定位风险”，可对比同一位置的风险色块和游戏底图；
- 调整风险图透明度；
- 鼠标滚轮缩放；
- 左键或中键拖动；
- 点击“适应窗口”看全图，“100%”查看原始比例。查看完点击“返回功能拓展”。

::: info
风险图是使用固定参数离线估算的结果，不代表实时遮挡、特效、昼夜和游戏更新后的所有情况。
:::
